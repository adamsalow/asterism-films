# Asterism Films Website

A one-page static website ready for GitHub Pages.

## Files
- `index.html` — page content
- `styles.css` — design and responsive layout
- `script.js` — mobile menu, current year, and subtle reveal animation
- `assets/asterism-logo.png` — logo

## Publish with GitHub Pages
1. Create a new public repository, for example `asterism-films`.
2. Upload all files and folders in this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then click **Save**.
6. GitHub will provide a live URL after deployment.

## Connect asterismfilms.com later
In your repository, open **Settings → Pages**, enter `asterismfilms.com` under **Custom domain**, and save. GitHub will show the DNS records to add at GoDaddy.

## Edit text
Open `index.html` in any text editor. The project cards are under the `Work` section.
